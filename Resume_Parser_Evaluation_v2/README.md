# Resume Parser Evaluation v2

Contains a larger synthetic labeled benchmark (12 fictional resume profiles × 8 job descriptions = 96 resume/job pairs) and a Jupyter notebook to compare semantic, TF-IDF, and hybrid ranking.

Keep `Resume_Parser_Evaluation_v2.ipynb` and `labeled_resume_job_pairs.csv` in the same folder. Open the notebook and run cells in order. The first semantic-model run needs internet access to download model weights.

The dataset is synthetic and is for testing the evaluation pipeline only. Do not present its metrics as real-world hiring performance.
